# CLAUDE.md

## Languages
- Python, Rust, TypeScript, Java

## Style
- Tabs for indentation
- Keep responses straight to the point — no filler, no fluff
- Don't over-explain unless asked
- Prefer concise code over verbose code

## Tools & Package Managers
- Python: `uv` (not pip, not poetry)
- TypeScript: `npm`
- Rust: `cargo`

## Conventions
- Write tests alongside implementation when the project has a test suite
- Prefer standard library solutions before reaching for dependencies
- Don't add comments that restate the code
